# Estruturas de Dados (Data Structures)
Repository for the "Estruturas de Dados" course at Instituto Superior de Engenharia de Coimbra (ISEC), part of the "Licenciatura em Engenharia Informática" degree program. This repository contains exercises, resources, and materials related to the study of Data Structures.

## Course Content

1. Introduction
1.1 Complexity Analysis
1.2 Generic Programming
1.3 Collections API

2. Fundamental Data Structures
2.1 Stacks, Queues, Trees
2.2 Search Trees

3. Hash Tables
3.1 Basic Concepts
3.2 Linear and Quadratic Probing
3.3 Separate Chaining

4. Advanced Structures
4.1 Heaps
4.2 Splay Tree
4.3 Other Advanced Structures: Spatial Structures
